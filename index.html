WORLD TREE & FIVE REALMS // 世界命根・五界門扉

世界樹與五界門扉的記憶織網

世界樹為亞雷利塔的命根子，枝葉銘刻萬物資訊、排出蘊含強大力量的琥珀樹脂，根部則封存歷經古神紀至救贖紀五次「世界重置」的舊日記憶；無高低之分的現界、天界、魔界、冥界與幻想界，唯有透過各界之門方能彼此連通。

MOFENG FEDERATION // 魔風聯邦・八大直轄市

魔風島的霓虹夜色與市井煙火

由「極惡之師」赤夜風竹統領的新興強國，短短十年間於魔風島崛起。從摩天霓虹交錯的首都霍普、紅燈籠綿延的商都天御、海風音樂廳迴盪的瑪捷塔，至山頂歌德競技場阿瑞納，由軍團八部隊與九人私兵「冥府神傑」共同守護。

HAVIDORN DRAGON EMPIRE // 龍皇島・九紋龍印

哈維德恩龍族帝國與蒼穹浮島

「寂滅龍皇」德貢・阿茲拉格統御的龍皇島，國土橫跨本島、浮空島與深海，東西方龍族在此共存。身為現界肉體最強種族，龍族每開啟一階「九紋龍印」皆能突破肉身極限，至第九印更將覺醒專屬龍種稱號與神威。

ABYSSAL MAW & MONOCHROME VOID // 深淵之口・萬寂虛域

丹格深淵浪潮與無色萬寂虛域

丹格市邊緣的黑紫色「深淵之口」潛伏著吞噬魔力的深淵魔獸與淵蝕五系；而表面包裹著外界虛空力的「萬寂虛域（無色境域）」與每 24 小時隨機顛倒層級的「冥界」，則是連世界樹與世界重置也無法干涉的禁忌領域。

CELESTIAL SANCTUM & FLOWERS OF TRUTH // 天界浮島・極真圃

米加百列浮空聖域與識真之花

天界「米加百列天國」的古老浮島受初代天神庇護，歷經數千萬年重置仍留存古神紀遺蹟；而在星光與金木樨花香之間，隱秘組織「極真圃」正以六朵「識真之花」為核心遊走四界，追尋世界重置前的終極真相。
